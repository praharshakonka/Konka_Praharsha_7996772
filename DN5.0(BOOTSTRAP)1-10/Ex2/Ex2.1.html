Bootstrap Folder Structure

|---------- bootstrap/
|               |
|               |
|               V
|              css/
|                |
|                V
│            bootstrap.min.css   (Styling file)
│
├──---------js/
|             |
|             V 
│      bootstrap.bundle.min.js   (JavaScript plugins)
│
├──--------icons/
             |
             V 
        SVG icons files (optional)

Explanation:

CSS folder contains styling files.

JS folder contains interactive JavaScript files.

Icons folder contains Bootstrap icon files.
